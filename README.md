# XEMO Personal Hub

Personal website, technical blog and professional portfolio.

**Current version:** 0.4.1 — LinkedIn Conversation Integration

- [Live website](https://arsenioxemo.github.io/)
- [Technical blog](https://arsenioxemo.github.io/blog/)
- [Engineering wiki](docs/wiki/README.md)
- [Release history](docs/wiki/releases.md)

Built with Astro, Markdown and GitHub Pages. Consent-gated analytics, automated quality gates and no additional hosting cost.

## Local development

Use Node.js 24, run `npm ci`, then `npm run dev`. Build with `npm run build`. Changes go through pull requests and CI.
